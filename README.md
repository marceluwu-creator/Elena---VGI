# Elena Morales — Banco de conocimiento VGI

Sitio estático para GitHub Pages. **Toda la ficha publicada es pública**; solo contiene información ficticia.

## Publicación rápida (sin programar)

1. Inicia sesión en https://github.com y crea un repositorio **público** llamado `vgi-elena`.
2. Abre el repositorio y selecciona **Add file → Upload files**. Carga `index.html`, `elena-vgi.txt` y `.nojekyll` (el archivo `README.md` es opcional).
3. Confirma con **Commit changes**.
4. En **Settings → Pages → Build and deployment**, elige **Deploy from a branch**, rama `main`, carpeta `/(root)` y **Save**.
5. Tu dirección será `https://TU_USUARIO.github.io/vgi-elena/` (reemplaza TU_USUARIO por tu usuario real).
6. Abre el enlace en una ventana privada para verificar que se ve sin iniciar sesión.
7. En Copilot → Editar agente → Conocimiento → Agregar sitio web público, pega la dirección del paso 5. No uses la dirección de `github.com` ni el enlace de descarga del ZIP.
8. Prueba preguntas concretas: «¿Qué resultado tiene el SPPB de Elena?» (7/12), «¿Cuál es su MoCA?» (26/30) y «¿Qué resultado tiene LSNS-6?» (11/30).

## Limitación fundamental

Microsoft 365 Copilot fundamenta respuestas de sitios públicos con contenido **indexado en Bing**. El sitio recién publicado puede tardar en aparecer en el índice, o no aparecer; que la URL sea aceptada **no garantiza** que Copilot encuentre la ficha ni que reproduzca todos los valores con precisión. Verifica que sus respuestas sean fieles a la fuente antes de usarlo con estudiantes. Si no responde, mantén los puntajes críticos dentro de las instrucciones del agente.

La URL de GitHub Pages propuesta contiene **un solo nivel** de ruta y no tiene parámetros de consulta.

**No publiques** información de personas reales, rúbricas o respuestas esperadas del docente.

Referencias oficiales: https://docs.github.com/en/pages/quickstart y https://learn.microsoft.com/en-us/microsoft-365/copilot/extensibility/agent-builder-add-knowledge
